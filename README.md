# DietMate

DietMate is a diet planning system designed to help users create and follow customized meal plans with ease. The application supports two primary roles:

**Admin:** Responsible for managing the system, including user records, and has the ability to add, update, or delete features.
**User:** Can log in, manage their personal diet plans, and track food intake effectively.

## ✨ Features

**Admin Capabilities**
* Manage user records: add, update, or delete user information.
* Oversee system functionalities and make necessary adjustments.

**User Functionalities**
* Secure login to access personalized dashboard.
* Create and manage customized diet plans.
* Track daily food intake and monitor progress.

## 🚀 Getting Started

### Prerequisites

* Java Development Kit (JDK) installed on your machine (Java 11 or higher recommended).
* Eclipse IDE or any other Java-compatible IDE.

### Installation

1.  Clone the repository:
    ```bash
    git clone [https://github.com/ayushhCreator/DietMate.git](https://github.com/ayushhCreator/DietMate.git)
    ```
2.  Open the project in your preferred IDE (Eclipse recommended).
3.  Build the project to resolve any necessary dependencies.
4.  Run the application.

## 💻 Usage

**Admin Access:**
* Log in using admin credentials.
* Manage user records and system features.

**User Access:**
* Register or log in with existing credentials on the login page.
* Navigate to the "Create Plan" section to define your dietary goals and meal preferences.
* Use the "Food Log" page to record your meals, specifying quantities and times.
* Monitor your dietary progress on your personalized dashboard.
